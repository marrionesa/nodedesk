# Nodedesk

## Gestiona tus proyectos Node.js desde un solo lugar

Nodedesk es una aplicación de escritorio para crear, importar y ejecutar tus proyectos Node.js localmente. Organiza tus proyectos, enciéndelos cuando los necesites y consulta todo lo que ocurre sin cambiar constantemente de terminal.

[Descargar Nodedesk](https://github.com/marrionesa/nodedesk/releases/latest) · [Ver el repositorio](https://github.com/marrionesa/nodedesk)

## Todo tu entorno Node.js, más sencillo

- **Crea proyectos en segundos** con plantillas para Express, Next.js, NestJS, Fastify, Hono, Node.js, Socket.io y APIs REST con JWT.
- **Importa proyectos existentes** desde archivos `.zip`, `.tar.xz` o `.tar.gz`.
- **Añade carpetas locales** y ten todos tus proyectos organizados en un mismo panel.
- **Enciende y apaga proyectos** con un solo interruptor.
- **Accede a dominios locales** como `mi-api.local` para trabajar cómodamente en cada proyecto.
- **Elige la versión de Node.js** de cada proyecto: 18, 20, 22 o 24.
- **Consulta los logs en vivo** con filtros, historial y opción de reinicio.
- **Edita tus variables `.env`** desde una interfaz visual con secretos protegidos.
- **Comparte proyectos temporalmente** mediante túneles públicos con `cloudflared`.
- **Continúa exactamente donde lo dejaste** gracias al registro persistente de proyectos.
- **Trabaja con la bandeja del sistema**, atajos globales y temas claro y oscuro.

## Descarga

Descarga la versión más reciente desde la página de [GitHub Releases](https://github.com/marrionesa/nodedesk/releases/latest).

| Sistema | Formato                                                |
| ------- | ------------------------------------------------------ |
| Windows | Instalador `.exe`                                      |
| macOS   | Instalador `.dmg` universal para Intel y Apple Silicon |
| Linux   | `.AppImage` o paquete `.deb`                           |

La aplicación incluye actualización automática en las versiones compatibles.

## Requisitos

Para utilizar la aplicación descargada solo necesitas un sistema compatible y Node.js instalado para ejecutar tus proyectos.

De forma opcional, puedes instalar:

- `fnm` o `volta` para utilizar distintas versiones de Node.js por proyecto.
- `cloudflared` para crear enlaces públicos temporales.

## Primeros pasos

1. Descarga e instala Nodedesk desde [GitHub Releases](https://github.com/marrionesa/nodedesk/releases/latest).
2. Abre la aplicación y elige una opción: crear desde una plantilla, importar un archivo o añadir una carpeta existente.
3. Selecciona la versión de Node.js que quieras utilizar.
4. Enciende el proyecto desde el panel.
5. Abre el dominio local, revisa los logs o comparte el proyecto mediante un túnel.
